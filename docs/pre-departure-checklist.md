# Pre-Departure Checklist

> Canonical editable version lives in Notion, where this is duplicated per trip. This file is the version-controlled mirror.

A reusable template for any time a core holder travels — most often Sunshine. Duplicate, date it, check items off. Do not rebuild it from memory each trip.

## How to use it

Duplicate → rename with the trip dates → work down the list. Anything unchecked at departure is a known gap, not a surprise.

## Content and assets

- [ ] Flyer for the next event batched and dated
- [ ] Studio reel recorded (one per month, reusable)
- [ ] Captions drafted for anything scheduled to post while away
- [ ] Canva files left in a state someone else can open and edit

## Handoffs

- [ ] Named who holds the group thread while away
- [ ] Named who can post to social without asking
- [ ] Confirmed someone other than the traveler can open the venue
- [ ] Confirmed the venue partner knows who to contact

## Money and access

- [ ] Any sponsor payments due are cleared or scheduled
- [ ] Whoever needs it has access to the payment method
- [ ] Nothing time-sensitive waiting only on the traveler's approval

## The Well

- [ ] Updated current state on anything the traveler owns
- [ ] Set anything at risk of stalling to a realistic state, not an optimistic one
- [ ] Noted in Flow Motion if the trip makes this a minimum viable month

## The judgment call before leaving

Ask once: **is this a normal month while I'm gone, or a minimum viable month?**

Answer it before departure, not from the road. If unclear, call it minimum viable — recovering from underpromising is easy.

## Why this exists

The traveling holder is the single point of failure the operations guide never mitigated. This does not remove the dependency. It makes the dependency visible in advance.
