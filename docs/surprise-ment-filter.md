# The Surprise-ment Filter

> Canonical editable version lives in Notion. This file is the version-controlled mirror.

A surprise-ment is an unplanned opportunity that arrives without warning. This filter exists so the answer is a decision, not a reflex.

## The 48-hour window

A surprise-ment gets 48 hours from the moment it lands. If no decision is reached in that window, the answer is no by default.

This is a proposal, not an inherited rule — the operations guide never specified timing. Change it if the team's real rhythm differs.

## The six steps

1. **Name it plainly.** What is actually being asked, in one sentence, without the excitement.
2. **Check the well.** Which level does this draw from? If Source is not flowing, a higher-level yes borrows against something that does not exist.
3. **Name the true cost.** Not just money — hours, attention, and who specifically loses capacity.
4. **Ask two others.** Two of three must feel a yes. One person's enthusiasm is not a quorum.
5. **Make the call.** Green-light, shift lower in the well, let it sit, or release.
6. **Log it in Depanty.** The no teaches as much as the yes.

## Clean-no language

A clean no protects the relationship:

> "Thank you for thinking of us. We can't hold this one well right now, and we'd rather say no than do it halfway. Please keep us in mind for the next one."

No invented excuse. No vague maybe that leaves someone waiting.

## Why the default is no

Silence is already a decision. Making the default explicit means an unanswered surprise-ment does not quietly become a yes through drift.
