# The Minimum Viable Month

> Canonical editable version lives in Notion. This file is the version-controlled mirror.

This closes a named gap: the whole efficiency model hinges on one monthly Cohoe with no defined fallback if it is missed or Sunshine is out.

## The question this answers

If no one has capacity to plan this month, what still happens?

## What holds without a Cohoe

- **Open Studio Days / drop-ins** run on the recurring page. The date updates; the page is never rebuilt.
- **The batched flyer** from the previous month gets its date swapped.
- **The 30-second studio reel** gets reused. One per month, not one per event.
- **The venue partner** confirmation carries from the standing arrangement.
- **Book Club** continues on its existing weekly cadence — the container was already named with an end date.

That is a real month. Small, honest, and open.

## What does not happen

- No new workshop concept. The monthly workshop is the first thing to drop.
- No pop-up. Planned presence needs planning.
- No sponsor outreach push.
- No new content beyond what was already batched.

Naming what drops is what makes the fallback usable. Otherwise everything feels equally urgent and nothing gets released.

## The trigger

Any one of these makes the month minimum viable:

- The Cohoe did not happen and there is no realistic date this week
- Sunshine is traveling and pre-departure batching did not complete
- Two or more core holders are at **Needs rest**
- The water is rough for a reason outside the work

Nobody has to justify calling it. One person naming it is enough.

## How to call it

Say it plainly in the group: *"This is a minimum viable month."*

Then in The Well, set Monthly Workshop to `Not started` for the cycle and leave Open Current at `In progress`. The databases should reflect the truth, not the aspiration.

## What this protects

A missed Cohoe is not a failure — it is a month where the studio stayed open and nobody burned to keep an unnecessary promise.

**The well does not run dry from resting. It runs dry from drawing while empty.**
